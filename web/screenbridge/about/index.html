About ScreenBridge

Linux audio sharing should feel like a button, not a project.

ScreenBridge turns the repeated virtual-sink setup into a small desktop application that can start, restore, and recover an audio-sharing session.

The problem

Linux can share computer sound, but many calling and recording apps only show microphone inputs. Getting desktop audio into those apps often means creating virtual devices by hand, moving application streams, and remembering how to undo everything afterward.

ScreenBridge packages that workflow into a clear interface: choose where you listen, choose your microphone, and start sharing.

Designed around control

Temporary changes

Audio routes and virtual inputs exist only while a ScreenBridge session is active.

Recoverable sessions

Setup state is saved locally so interrupted sessions can still be cleaned up.

Separate by default

Computer audio and microphone audio remain distinct unless you choose to mix them.

Open source

The application, tests, packaging, and release automation are available for review.

Privacy

ScreenBridge does not create an account, upload audio, or connect to an Elixpo service. It configures the audio server running in your own desktop session. The call, recording, or streaming application you select receives the resulting input and remains responsible for its own privacy behavior.
