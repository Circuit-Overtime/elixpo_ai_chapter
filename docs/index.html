Training Binary-Weight Diffusion Models from Scratch: A Controlled MNIST and CIFAR-10 Study

Ayushman Bhattacharya, Anwesha Chakraborty, and Nihal Gazi

Read the PDF Code and artifacts

Abstract

At one bit per weight, post-training quantization can destroy a diffusion model's denoising function. We isolate how much can be recovered by optimizing with binary weights in the forward pass using a parameter-compatible small residual U-Net. The study compares FP32 training, zero-shot PTQ, native W1A32 training, warm-started quantization-aware training, and a W1A1 core under matched budgets and three training seeds. On MNIST, native W1A32 substantially mitigates PTQ collapse but remains behind FP32. On CIFAR-10, even the compact FP32 control fails the evaluation audit, so the stress test does not establish natural-image performance. The result is deliberately bounded: optimization path matters at one bit on MNIST, while a general teacher-free solution to binary diffusion remains open.

Status

This manuscript is a preprint and has not undergone peer review. Its CIFAR-10 result is reported as a failed small-model stress test, not as competitive natural-image generation.
