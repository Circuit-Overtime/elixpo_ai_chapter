# Contributing to OctaBit

Start with an issue or an Elixpo Discussion before undertaking a large change. Keep pull requests focused, explain the user-visible result, and run the commands declared in `.elixpo/project.yml`. By participating, you agree to the repository's code of conduct.

- Issues: https://github.com/elixpo/octabit/issues
- Discussions: https://github.com/orgs/elixpo/discussions
