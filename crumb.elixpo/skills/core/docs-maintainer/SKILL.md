---
name: docs-maintainer
description: Create or update concise user-facing documentation that matches the product.
---

1. Verify commands, names, links, and behavior against the current repository.
2. Lead with what the user can accomplish, not implementation internals.
3. Keep setup examples copyable and avoid undocumented prerequisites.
4. Preserve the document's established voice and structure.
5. Remove stale or duplicated guidance when replacing it.
