  Description     : self-hosted agent harness and natural-language terminal

Crumb combines a normal interactive shell with an optional, supervised agent
runtime. It keeps execution, tool permissions, sessions, memory, and model
selection under the user's control. Ordinary shell use does not require an AI
provider.

The package is useful to users who want an inspectable local harness instead
of delegating shell control, credentials, and execution policy to a hosted
agent. It supports replaceable model infrastructure and uses Pollinations as
its default inference layer.

I intend to maintain the package with the Debian Rust Team. The upstream
repository contains a Debian-specific feature profile and preliminary source
packaging. Its sole Rust dependency not yet in unstable is reedline 0.52.1;
that dependency will be coordinated through the Rust Team before upload.
