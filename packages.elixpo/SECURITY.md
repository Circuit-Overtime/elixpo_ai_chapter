# Security policy

Do not open a public issue for vulnerabilities involving package installation,
signing, update delivery, privilege boundaries, or supply-chain integrity.

Use GitHub’s private vulnerability-reporting form for this repository, or email
`security@elixpo.com` when that route is unavailable. Include the affected
package and version, supported reproduction details, impact, and any suggested
mitigation. Never include private keys, access tokens, or unrelated personal
data.

Maintainers will acknowledge a complete report, investigate the affected
release and distribution path, and coordinate remediation before public
disclosure where practical. Supported versions are those currently marked
maintained in the canonical package registry.
