# Support

For installation or application problems, open a public issue and include the
package version, Linux distribution, desktop environment, display protocol,
reproduction steps, logs with secrets removed, and the result you expected.

- Catalogue and installers: <https://packages.elixpo.com>
- Public issues: <https://github.com/elixpo/packages.elixpo/issues>
- Package operations: [`docs/apt-repository.md`](docs/apt-repository.md)
- Maintainer guide: [`docs/maintainers.md`](docs/maintainers.md)

Security reports follow `SECURITY.md`. Community conduct concerns follow
`CODE_OF_CONDUCT.md`. Maintainers cannot guarantee support for unmaintained
versions, unofficial rebuilds, or distributions outside a package’s stated
support record.
