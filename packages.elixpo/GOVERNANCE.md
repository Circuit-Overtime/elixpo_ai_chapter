# Governance

Elixpo Packages is maintainer-led. Maintainers are accountable for package
identity, release review, signing operations, repository metadata, supported
platform claims, and the public distribution surface.

Contributors retain attribution for accepted work. A contribution does not by
itself grant release authority, signing access, organization membership, or a
permanent maintainer role. Changes to signing keys, package names, stable
installer URLs, deployment ownership, or release workflows require explicit
lead-maintainer approval and a documented rollback path.

Canonical organization classification is maintained in `elixpo/elixpo`.
Application source and releases remain authoritative in this repository.
