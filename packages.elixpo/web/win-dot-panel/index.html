Three simple steps

A shortcut that feels familiar.

01 / INSTALL

Add the package

Use the signed APT repository, or download the latest Debian package from GitHub.

02 / CONNECT

Set your shortcuts

In your desktop keyboard settings, assign Super + . to /usr/bin/win-dot-panel toggle and Super + V to /usr/bin/win-dot-panel toggle-clipboard. See the shortcut setup guide ↗ for GNOME and KDE steps.

03 / PICK

Find it in a second

Search, browse, or choose a recent item. Your clipboard history stays on your computer.

Get started

Install once. Keep it up to date.

APT repository

Add the signed repository once. After that, normal APT updates include Win Dot Panel.

Checking repository availability…
curl -fsSL -o /var/tmp/win-dot-panel-install.sh https://packages.elixpo.com/win-dot-panel/install.sh && bash /var/tmp/win-dot-panel-install.sh
✓ Installed — your clipboard, one shortcut away.If clipboard history stays empty, log out and log back in once to activate it.
Prefer the manual APT steps? ↗ 
sudo apt update && sudo apt install --only-upgrade win-dot-panel
