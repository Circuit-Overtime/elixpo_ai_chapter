Win Dot Panel guide

Emoji and clipboard history, always close by.

Use two familiar shortcuts to open a searchable picker without leaving the application where you are working.

Set up shortcutsTroubleshooting

Set up your shortcuts

Emoji and symbols

Assign Super + . to /usr/bin/win-dot-panel toggle.

Clipboard history

Assign Super + V to /usr/bin/win-dot-panel toggle-clipboard.

GNOME

Open Settings → Keyboard → View and Customize Shortcuts → Custom Shortcuts. Add each command and record its key combination.

KDE Plasma

Open System Settings → Shortcuts, choose Add New → Command or Script, and add each command. KDE calls the Super key Meta.

Using the panel

  1. Open it. Press your shortcut or launch Win Dot Panel from the applications menu.
  2. Choose a tab. Browse emoji, clipboard items, kaomoji, or symbols.
  3. Search naturally. Type a name or keyword to narrow the current collection.
  4. Pick an item. Text is inserted where you were working when desktop access is available. Screenshots can be copied or pasted from their card menu.
  5. Close it. Press Esc or use the same shortcut again.

Clipboard history

Copied text and screenshots appear in the Clipboard tab. Use a card's menu to copy it again, pin it, or remove it. Pinned items remain easy to find.

Clipboard history is stored on your computer. It is not synchronized or uploaded by Win Dot Panel.

Troubleshooting

The shortcut types a letter or opens another picker

IBus may already use Super + .. Change its emoji shortcut or select another combination, then confirm there is only one matching custom shortcut in desktop settings.

gsettings set org.freedesktop.ibus.panel.emoji hotkey "['<Super>semicolon']"

Clipboard history stays empty

Log out and back in once after installation so the background application starts with your desktop session. On Wayland, approve keyboard and clipboard access when prompted.

An item is copied but not inserted

Desktop security may prevent direct insertion. Paste normally with Ctrl + V. On Wayland, reopen the app and approve the desktop access request.

The panel does not open

/usr/bin/win-dot-panel status
/usr/bin/win-dot-panel quit
/usr/bin/win-dot-panel toggle

The quit command clears an older background process. The final command starts it again and opens the panel.

Update or remove

sudo apt update
sudo apt install --only-upgrade win-dot-panel

To remove the application, run sudo apt remove win-dot-panel. Removing the package does not automatically erase your saved clipboard database.
