---
name: codebase-map
description: Map an unfamiliar repository before making changes. Use for onboarding, architecture questions, or broad implementation requests.
---

1. Run `detect_stack` before guessing the project stack.
2. Read the nearest contributor instructions and primary manifests.
3. Identify entry points, trust boundaries, tests, and generated files.
4. Prefer targeted searches over broad file dumps.
5. Summarize only facts supported by paths or tool results, then choose the smallest change surface.
