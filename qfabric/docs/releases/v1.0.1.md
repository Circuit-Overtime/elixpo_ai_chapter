# QFabric v1.0.1 — Authorship Correction

QFabric v1.0.1 is a metadata and research-artifact correction to the stable
v1.0 release. It adds Anwesha Chakraborty (`anwesha.elixpo@gmail.com`) as a
co-author alongside Ayushman Bhattacharya (`ayushman@myceli.ai`).

## Corrected surfaces

- Python package author metadata.
- Repository citation metadata in `CITATION.cff`.
- IEEE manuscript author block and PDF author metadata.
- QFabric artifact entry in the manuscript bibliography.
- Release paper, manifest, checksums, wheel, and source distribution.

There are no runtime, CLI, QTask ABI, schema, experimental-data, or result
changes relative to v1.0.0.

## Installation

```bash
python3 -m pip install qfabric==1.0.1
qf --help
```

## Verification

The complete hardware-independent test suite, lint checks, package validation,
clean installation, manuscript build, and checksum audit are rerun for this
patch release.
