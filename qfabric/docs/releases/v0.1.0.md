# QFabric v0.1.0 — Research Artifact

QFabric v0.1.0 is the first citable research release of the contract-driven
Linux–RTOS recovery prototype for the Arduino UNO Q.

## Research contribution

QFabric detects sustained empirical timing-contract violations, rejects
semantically or temporally inadmissible moves, switches eligible tasks only at
a zero-inflight epoch boundary, and commits or rolls back after post-switch
observation. The release deliberately does not claim hard real-time guarantees
or universal superiority over platform-specific scheduler tuning.

## Principal result

In the controlled four-node Linux load-shift replay, ordinary Linux produced a
111.30 ms p95 and 67.3% miss rate against an 80 ms graph deadline. QFabric
recovery reduced p95 to 70.61 ms and misses to 3.7%. A tuned `SCHED_FIFO`
baseline remained stronger at 23.91 ms and zero misses; the manuscript treats
that comparison as a central claim boundary.

## Included evidence

- Direct UNO Q timing, payload, direction, load, concurrency, and LED campaigns.
- Hardware recovery success and rollback scenarios.
- Stage-by-stage specifications, findings, and independent audit reports.
- Stage 11 evaluation across four graph models and seven baselines.
- Source-backed paper graphs, tables, equations, and testbed photograph.
- Python wheel and source distribution for the `qf` research CLI.

## Installation

```bash
python3 -m pip install qfabric==0.1.0
qf --help
```

Hardware commands require the matching firmware and a full repository checkout.

## Verification

The release process runs the complete hardware-independent unit suite, Ruff,
bytecode compilation, package build, metadata validation, and clean-wheel
installation. `SHA256SUMS` covers the attached paper, distributions, release
notes, and final Stage 11 evaluation report.

The local release bundle can be regenerated after building the Python
distributions and paper:

```bash
python3 scripts/build-release-bundle.py --version 0.1.0
```
