# QFabric v1.0.2 — Repository Migration

QFabric v1.0.2 moves the canonical project home from
`Circuit-Overtime/QFabric` to [`elixpo/qfabric`](https://github.com/elixpo/qfabric).

## Updated metadata

- Python package homepage, documentation, issue tracker, and source URLs.
- Repository and preferred-citation URLs in `CITATION.cff`.
- README issue links and hardware setup clone instructions.
- Manuscript QFabric reference and changelog release links.
- Release manifest, paper, wheel, and source distribution version metadata.
- Plain-language project README with the real UNO Q testbed photograph.
- Explicit prepublication rights notice for the manuscript and its original
  visual material, separate from the Apache-2.0 software license.

There are no runtime, CLI, QTask ABI, schema, experimental-data, result, or
authorship changes relative to v1.0.1.

## Installation

```bash
python3 -m pip install qfabric==1.0.2
qf --help
```
