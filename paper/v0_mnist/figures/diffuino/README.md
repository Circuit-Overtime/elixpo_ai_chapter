# Diffuino figure assets

Place publication-ready Diffuino images in this directory. The paper
automatically includes diffuino-board.jpg when that file is present, so the
LaTeX source still builds before the photograph is added.

Suggested files:

- diffuino-board.jpg: the primary board-and-matrix photograph used by the paper;
- diffuino-terminal.png: terminal output showing requested and classified digit;
- diffuino-sequence.png: several denoising frames in chronological order; and
- diffuino-setup.jpg: a wider photograph of the complete physical setup.

Use even lighting, keep the LED matrix in focus, crop unused background, and
retain a high-resolution original. Remove IP addresses, serial numbers, SSH
details, and other private information from terminal captures. Only add images
whose publication rights are clear.
