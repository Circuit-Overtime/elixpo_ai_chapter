# Support

Elixpo is an open-source project foundry, not a guaranteed support service.

- Use [GitHub Discussions](https://github.com/orgs/elixpo/discussions) for
  questions, Chapter proposals, research discussion, and service feedback.
- Use the owning repository's issue tracker for reproducible project defects.
- Use [SECURITY.md](SECURITY.md) for vulnerabilities or sensitive reports; do
  not publish exploit details in an issue.
- Use the correction and evidence routes linked from the relevant public record
  for lifecycle, contributor, history, or attribution corrections.

Responses are best-effort. Repository lifecycle labels describe current intent
and do not promise permanent maintenance, uptime, acceptance, or a response
deadline.
